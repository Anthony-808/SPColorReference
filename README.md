# Color Reference App

A local web app for viewing standardized color values.

## Features
- Live color display
- RGB display
- HEX conversion
- Named color support
- Search named colors
- Autocomplete dropdown
- RGB/HEX display
- Markerbar

## Tech Stack
- HTML
- CSS
- JavaScript

## Future Features
- Dropdown polish
- Accessibility tools
- Information pop-ups
- More color systems
- Responsive design
- Modularization

## Running the App
Open index.html in a browser.
